Postdove GitHub ↗

Uji API dari desktop.

Susun request HTTP, simpan ke koleksi, lalu periksa status, header, dan body respons di satu workspace lokal.

Jalankan dari source Lihat kode

Contoh request dan respons

GET{{base_url}}/health
{
  "status": "ok",
  "service": "example"
}
200 OKapplication/json

Fitur Postdove

  • Koleksi dan environment

    Kelompokkan request dalam folder, atur header bawaan, dan arahkan kursor ke variabel untuk melihat nilainya.

  • Format Postman v2.1

    Impor file koleksi yang sudah ada atau ekspor koleksi Postdove sebagai JSON.

  • MCP server lokal

    Kirim request lewat tool send_http_request dari MCP client yang mendukung stdio.

Jalankan Postdove

Siapkan Node.js, Rust, dan dependensi Tauri untuk sistem operasi kamu.

git clone https://github.com/fiansyahm31125/postdove.git
cd postdove
npm ci
npm run tauri dev
