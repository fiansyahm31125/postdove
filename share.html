PostDove

Buka folder yang dibagikan

  1. Buka PostDove desktop dan pilih Online Sharing.
  2. Salin link di atas ke kolom repository atau undangan. Kamu juga bisa memasukkan nama repository langsung.
  3. Masukkan token GitHub milikmu yang memiliki akses baca ke repository privat, lalu klik Open shared folders.

Masukkan token hanya di PostDove desktop. Folder akan muncul di Collections → Online folders · Read-only.
