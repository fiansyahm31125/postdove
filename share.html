PostDove

Buka folder yang dibagikan

Pratinjau di Google Drive
  1. Buka PostDove desktop dan pilih Online Sharing.
  2. Login dengan akun Google yang diberi izin Viewer oleh pengirim.
  3. Tempel link undangan atau link Google Drive, lalu klik Open shared folder.

Jika Google Drive membuka file di browser tetapi PostDove belum bisa membacanya langsung, unduh file JSON dari Drive dan pilih Import downloaded JSON di PostDove.

Folder akan muncul di Collections → Online folders · Read-only.
